### 과제 배경:
- 현재 저는 AX 교육에 투입되어 마지막 과정으로 0.5일 기획(문서 작성)을 하고 1.5일간 미니 프로젝트를 개발해야 됩니다.
- 미니 프로젝트는 AI 에이전트를 만드는 것입니다.

### 배경 기술:
- 회사에서 프로젝트를 시작하면 문서관리 시스템으로 컨플루언스를 사용합니다.
- 컨플루언스에 온보딩 매뉴얼과 프로젝트에 관련된 문서들을 정리하고 공유합니다.

### 아이디어 초안:
##### 페인 포인트
- 온보딩이 된 신입 멤버의 경우, 프로젝트의 온보딩 매뉴얼을 찾기 어렵습니다.
  예1: 방화벽 설정, 보안 설정, 프로젝트 시스템들과 가입 및 사용 신청 등등 ...
- 온보딩이 된 신입 멤버의 경우, 프로젝트의 기본 정보를 찾아서 업무를 파악해야 합니다.
  예2: 이미 개발이 시작된 경우, 개발환경 구축 가이드 등을 찾아서 환경 구축도 해야 합니다.
##### 아이디어
- 컨플루언스 MCP를 AI 에이전트에 채택해서 공개된 API를 호출하여 상호작용을 하려고 합니다.
- 테스트를 위한 문서관리 프로젝트는 기존에 존재하는 오픈소스 프로젝트의 오픈된 컨플루언스를 대상으로 하려고 합니다.
  예3: 잠정적으로 Apache Software Foundation 의 컨플루언스를 생각하고 있습니다.
- 언어는 파이썬이고 langchain, langgraph 라이브러리를 쓸 것입니다.
- ai 에이전트 파트와 모델 서빙을 위한 fastapi 를 활용한 서버 파트, 그리고 서버를 호출하는 UI 부분인 html 파트로 나누어서 구현을 하려고 합니다.
- html 파트는 채팅 UI로 필요한 라이브러리들은 직접 include를 해서 html 파일 하나로 구현을 했으면 합니다.
##### 진입점
- 이런 프로젝트를 만들려고 하는데 구체적으로 기능 요구사항과 비기능 요구사항들을 도출해 내야 할 것 같습니다.
