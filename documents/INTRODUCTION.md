# INTRODUCTION.md — 컨플루언스 온보딩 Agent

1. SI/SM 프로젝트에 투입된 신입 멤버가 컨플루언스에서 온보딩 정보를 찾지 못해 겪는 비효율을 해결하는 AI 에이전트입니다.
2. 사전에 인덱싱한 문서를 RAG로 검색하고, 결과가 부족하면 MCP로 컨플루언스를 실시간 검색해 보완합니다.
3. 답변은 긴 문서를 그대로 링크하지 않고 필요한 부분만 요약해 인용하며, 근거가 없으면 "모른다"고 답해 환각을 방지합니다.
4. 1.5일 개발 범위에서는 실제 사내 컨플루언스 대신 Apache Hadoop의 공개 컨플루언스(HADOOP2)로 파이프라인 자체의 동작을 검증합니다.
5. LLM-judge로 출처 정확성을 채점해, 평가 질문 11건 중 약 70%(8건) 이상 통과를 오늘 산출물의 성공 기준으로 삼았습니다.
